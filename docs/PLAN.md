# 세계지도 그리기 — 기획서

> **표기 안내**
> 이 문서에는 이번 변경사항인 **대륙 선택**이 반영되어 있어요.
> 원래 기획서가 저장소에 없어서 기존 규칙 일부는 추정해서 적었어요. 그런 항목에는 `(추정)` 표시를 했어요. 원래 기획서와 다르면 원래 기획서를 따라 고쳐 주세요.

## 1. 게임 개요

- 세계지도 위에 나라 이름이 하나 나오면, 그 나라의 위치와 모양을 직접 그려요.
- 그린 결과는 실제 국경과 비교해서 점수와 등급을 매겨요. (추정)
- 출제는 큰 나라부터 작은 나라 순서예요.
- 지도는 **하나**예요. 어느 대륙에서 그리든 같은 세계지도가 채워져요.

## 2. 시작 화면

다음 일곱 개 버튼 중 하나를 골라요.

| 버튼 | 출제 대상 |
|---|---|
| 전 세계 | 아직 안 그린 모든 나라 |
| 아시아 | 아시아로 분류된 나라 중 안 그린 나라 |
| 유럽 | 〃 |
| 아프리카 | 〃 |
| 북아메리카 | 〃 |
| 남아메리카 | 〃 |
| 오세아니아 | 〃 |

### 버튼에 표시하는 정보

- **진행률**: `그린 나라 수 / 전체 나라 수`. 예: `유럽 21 / 44`
  - 전 세계 버튼은 전체 나라 기준으로 표시해요. 예: `전 세계 87 / 197`
- **평균 등급**: 그 대륙을 다 그렸으면 진행률 옆에 평균 등급을 표시해요. 예: `유럽 44 / 44 · A`
  - 평균 등급은 그 대륙 나라들의 점수 평균을 등급표로 바꾼 값이에요. 등급을 평균내는 게 아니라 점수를 평균내요.
  - 전 세계 버튼은 여섯 대륙을 다 끝냈을 때 전체 평균 등급을 표시해요.
- 진행 중인 대륙(1개 이상 그렸고 다 끝나지 않은 대륙)은 진행 막대로도 보여줘요.

## 3. 대륙을 골랐을 때

### 화면

- 고른 대륙이 화면에 꽉 차게 확대된 상태로 시작해요.
- 다른 대륙의 나라는 흐리게 표시해요. (불투명도 약 30%, 클릭·그리기 영향 없음)
- 이미 그린 나라는 대륙과 상관없이 모두 칠해진 상태로 보여요.
- 확대/이동은 기존처럼 자유롭게 할 수 있어요. "대륙 맞춤" 버튼으로 처음 화면으로 돌아와요.

### 대륙별 확대 범위

나라 모양에서 자동으로 범위를 계산하면 러시아(유럽 소속, 동쪽 끝이 180° 경선까지)나 오세아니아·알래스카(날짜변경선을 넘음) 때문에 범위가 엉뚱하게 넓어져요. 그래서 **대륙마다 확대 범위를 직접 정해서** 데이터에 넣어요.

| 대륙 | 서 | 남 | 동 | 북 | 비고 |
|---|---|---|---|---|---|
| 아시아 | 25 | -12 | 150 | 56 | |
| 유럽 | -25 | 34 | 60 | 72 | 러시아 전체는 화면 밖으로 나가요. 러시아를 그릴 때만 범위를 러시아에 맞춰 넓혀요. |
| 아프리카 | -26 | -36 | 58 | 38 | |
| 북아메리카 | -170 | 5 | -50 | 75 | 중앙아메리카·카리브 포함 |
| 남아메리카 | -92 | -56 | -32 | 14 | |
| 오세아니아 | 110 | -48 | 190 | 5 | 날짜변경선 너머(피지 등)를 이어서 보여줘요. 190 = -170 |

수치는 시작값이에요. 실제 화면에서 보고 조정해요.

### 출제

- 고른 대륙의 나라만 출제해요.
- 순서는 기존과 같이 **면적이 큰 나라부터** 작은 나라 순이에요.
- **전 세계**를 고르면 아직 안 그린 나라 전부가 출제 대상이에요. 순서는 마찬가지로 면적순이에요.

## 4. 진행과 저장

### 원칙

- 저장은 **하나**로 관리해요. 유럽 모드에서 그린 나라는 전 세계 모드와 다른 모든 화면에서도 그린 나라예요.
- 대륙을 중간에 바꿔도 돼요. 각 모드(전 세계 + 여섯 대륙)의 **다음 문제**는 따로 기억해요.

### 저장 구조

`localStorage` 키 하나에 저장해요. (추정: 기존에도 localStorage 사용)

```json
{
  "version": 2,
  "results": {
    "FRA": { "score": 87, "grade": "A", "drawing": [[2.1, 46.3], [2.4, 46.1]], "hintUsed": false, "at": "2026-11-12T10:00:00Z" }
  },
  "current": {
    "world": "CHN",
    "europe": "FRA",
    "asia": null
  },
  "celebrated": {
    "europe": true,
    "world": false
  }
}
```

- `results`: 나라 코드(ISO 3166-1 alpha-3)별 결과. 모드 구분 없이 하나예요. `drawing`은 화면 좌표가 아니라 경위도 좌표로 저장해서 확대 상태와 상관없이 다시 그릴 수 있게 해요.
- `current`: 모드별로 지금 출제 중인 나라. 대륙을 바꿨다가 돌아오면 이 나라부터 다시 나와요.
- `celebrated`: 완성 화면을 이미 보여줬는지. 같은 완성 화면을 두 번 띄우지 않으려고 둬요.

### 남은 나라 계산

모드별 "남은 나라 순서"를 따로 리스트로 저장하지 않고, 매번 계산해요.

```
남은 나라(모드) = 면적순 전체 목록
                 → 모드가 대륙이면 그 대륙 나라만
                 → results에 있는 나라 제외
```

- 이렇게 하면 유럽에서 프랑스를 그린 뒤 전 세계 모드로 가도 프랑스가 다시 나오지 않아요.
- `current[모드]`가 이미 다른 모드에서 그려졌으면 무시하고 남은 나라의 첫 번째로 넘어가요.
- 건너뛰기 기능이 있으면 (추정) 건너뛴 나라는 그 모드의 남은 목록 맨 뒤로 보내고, 이 순서만 `skipped[모드]`로 따로 저장해요.

### 기존 저장 데이터 옮기기

`version`이 없는(대륙 기능 이전) 저장 데이터를 읽으면 결과는 그대로 `results`로 옮기고 `current`는 비워요. 그린 기록은 사라지지 않아요.

## 5. 힌트 변경

- **이전**: "대륙 밝게 표시". 대륙 모드에서는 이미 대륙이 확대·강조되어 있어서 쓸모가 없어요.
- **변경**: 힌트를 쓰면 **대략적인 위치를 큰 원으로 표시**해요.
- 점수는 이전과 같이 **20% 깎여요** (최종 점수 × 0.8).

### 원 그리는 규칙

- 원은 나라 전체를 반드시 포함해요.
- 원의 중심은 나라 중심에서 무작위로 조금 비켜요. 그래야 원 중심만 보고 정답을 알 수 없어요.
- 반지름 = `max(나라를 감싸는 최소 반지름 × 2.5, 화면 짧은 변의 12%)`
  - 작은 섬나라도 원이 너무 작아지지 않게 화면 기준 최소 크기를 둬요.
- 중심 이동량은 `반지름 − 나라를 감싸는 최소 반지름` 이내에서 고르면 나라가 원 밖으로 나가지 않아요.
- 원은 반투명 테두리와 옅은 채우기로 표시하고, 그 나라를 그리는 동안 계속 보여요.

## 6. 완성 화면

### 대륙 완성 화면

대륙의 마지막 나라를 그리면 나와요. **어느 모드에서 그렸든** 나와요. (전 세계 모드에서 아프리카의 마지막 나라를 그려도 아프리카 완성 화면이 나와요.)

보여주는 내용:

1. **평균 점수**와 평균 등급
2. **잘 그린 나라** 상위 3개 (점수 높은 순)
3. **못 그린 나라** 하위 3개 (점수 낮은 순)
4. **내 그림과 실제 지도 비교**: 그 대륙을 확대한 지도 위에 내 그림(선)과 실제 국경(채움)을 겹쳐 보여줘요. 나라를 누르면 그 나라만 크게 비교해요.

버튼: `대륙 선택으로`, `전 세계 보기`

### 세계지도 완성 화면

여섯 대륙을 전부 끝내면 나와요. 마지막 나라가 어떤 대륙을 완성시키면서 동시에 세계를 완성시키면 **대륙 완성 화면 → 세계지도 완성 화면** 순서로 보여줘요.

보여주는 내용:

1. 전체 평균 점수와 등급
2. 대륙별 평균 등급 6개
3. 전 세계 잘 그린 나라 / 못 그린 나라 (각 5개)
4. 내가 그린 세계지도 전체와 실제 세계지도 비교

### 다시 하기 (추정)

완성한 대륙도 다시 그릴 수 있게 대륙 완성 화면에 `이 대륙 다시 그리기`를 둬요. 누르면 그 대륙 나라의 `results`만 지우고 `celebrated[대륙]`을 false로 돌려요. 세계 완성이 풀리면 `celebrated.world`도 false로 돌려요.

## 7. 데이터: `countries-ko.json`

각 나라에 `continent` 칸을 추가해요.

```json
{
  "code": "FRA",
  "name": "프랑스",
  "area": 551695,
  "continent": "europe"
}
```

- `continent` 값: `asia`, `europe`, `africa`, `north-america`, `south-america`, `oceania` 중 하나
- `code`, `name`, `area` 이름은 (추정). 기존 칸 이름이 다르면 기존 이름을 따라요.
- 남극은 출제 대상이 아니므로 대륙을 넣지 않아요. (추정)

대륙 이름과 확대 범위는 같은 파일이나 별도 `continents.json`에 둬요.

```json
[
  { "id": "europe", "name": "유럽", "bounds": [-25, 34, 60, 72] }
]
```

### 두 대륙에 걸친 나라

**한 대륙에만** 넣어요.

**규칙: 수도가 있는 대륙에 넣어요.** 러시아(모스크바 → 유럽)와 이집트(카이로 → 아프리카)에 공통으로 맞는 기준이에요. 러시아는 영토 대부분이 아시아라서 "영토가 넓은 쪽"은 기준이 될 수 없어요. 수도가 있는 대륙은 두 나라 모두 인구 대부분이 사는 대륙이기도 해요.

해외 영토나 멀리 떨어진 섬(스페인의 세우타, 예멘의 소코트라 등)도 같은 규칙으로 본토 수도를 따라가요.

| 나라 | 수도 | 넣는 대륙 |
|---|---|---|
| 러시아 | 모스크바 | 유럽 |
| 이집트 | 카이로 | 아프리카 |
| 튀르키예 | 앙카라 (아나톨리아) | 아시아 |
| 카자흐스탄 | 아스타나 (우랄강 동쪽) | 아시아 |
| 아제르바이잔 | 바쿠 (캅카스산맥 남쪽) | 아시아 |
| 조지아 | 트빌리시 (캅카스산맥 남쪽) | 아시아 |
| 아르메니아 | 예레반 | 아시아 |
| 키프로스 | 니코시아 (아나톨리아 남쪽 섬) | 아시아 |
| 인도네시아 | 자카르타 (자와섬) | 아시아 |
| 동티모르 | 딜리 (티모르섬) | 아시아 |
| 파푸아뉴기니 | 포트모르즈비 (뉴기니섬) | 오세아니아 |
| 파나마 | 파나마시티 (파나마·콜롬비아 국경 서쪽) | 북아메리카 |
| 트리니다드 토바고 | 포트오브스페인 (남아메리카 대륙붕 위 트리니다드섬) | 남아메리카 |

키프로스와 트리니다드 토바고는 흔히 정치·문화적으로 각각 유럽·북아메리카로 분류하지만, 이 규칙에서는 수도의 지리적 위치를 따라요.

## 8. 개발 순서

> 원래 기획서의 단계 목록이 저장소에 없어서, 이번 변경으로 추가되는 항목만 확실하게 적었어요. 나머지 단계는 원래 기획서를 그대로 따라요.

1. ~ 3. (원래 기획서 그대로)
4. (원래 4단계 항목 그대로) **+ 대륙 선택 화면과 대륙별 진행률** ← 이번 추가
   - `countries-ko.json`에 `continent` 칸 추가, `continents.json`(확대 범위) 추가
   - 시작 화면: 7개 버튼, 진행률, 완성 대륙 평균 등급
   - 대륙 모드: 대륙 맞춤 확대, 다른 대륙 흐리게, 대륙 나라만 면적순 출제
   - 저장 구조 `version: 2` 전환과 이전 데이터 옮기기
   - 모드별 `current` 기억, 대륙 바꾸기
   - 힌트를 "대략적인 위치 원 표시"로 교체 (점수 20% 감점 유지)
   - 대륙 완성 화면, 세계지도 완성 화면
5. 이후 (원래 기획서 그대로)

### 4단계 완료 확인 항목

- [ ] 유럽에서 그린 나라가 전 세계 모드와 다른 대륙 모드 지도에 칠해져 있다.
- [ ] 유럽에서 그린 나라가 전 세계 모드에서 다시 출제되지 않는다.
- [ ] 유럽 도중 아시아로 바꿨다가 유럽으로 돌아오면 아까 그 나라부터 나온다.
- [ ] 시작 화면 진행률 숫자가 실제 그린 나라 수와 맞다.
- [ ] 전 세계 모드에서 어떤 대륙의 마지막 나라를 그려도 그 대륙 완성 화면이 나온다.
- [ ] 마지막 나라로 대륙과 세계가 동시에 완성되면 두 화면이 순서대로 나온다.
- [ ] 완성 화면은 한 번만 자동으로 나온다. (새로고침해도 다시 안 뜬다)
- [ ] 힌트 원이 섬나라(예: 몰디브, 투발루)에서도 충분히 크고 나라를 포함한다.
- [ ] 힌트를 쓰면 점수가 정확히 80%가 된다.
- [ ] 두 대륙에 걸친 나라가 수도가 있는 대륙에만 집계된다. (러시아 → 유럽, 이집트 → 아프리카 등)
- [ ] 이전 버전 저장 데이터를 불러와도 그린 기록이 유지된다.
